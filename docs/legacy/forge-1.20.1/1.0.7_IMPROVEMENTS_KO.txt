Glitched Crown 1.0.7 - 요청 개선사항 구현 기록
================================================

1. 인챈트
- Tombstone/Corail 전용 soulbound ID 제거.
- Mending, Unbreaking 허용.
- registry path, enchantment description id, 또는 인챈트 태그가 soulbound / soul_bound / soulbind / soul_binding 계열이면 허용.
- 인챈트 테이블뿐 아니라 허용된 인챈트만 든 마법부여 책과의 모루 조합도 허용.
- 이미 인챈트된 Crown에도 추가 허용 인챈트를 붙일 수 있도록 isEnchantable=true.

2. 내구도
- 최대 내구도: 16,777,216.
- ItemStack.isDamageableItem 단계에서 Glitched Crown은 false 처리하여 일반 내구도 소모와 파괴를 막음.
- Mending/Unbreaking은 적용 허용 상태지만, 왕관 자체는 파괴되지 않으므로 실질적인 내구도 보존은 왕관 고유 특성이 우선함.

3. 삭제 광선 G
LivingEntity 처리:
  a. 무적/피격 지연 초기화
  b. hurt(source, maxHealth)
  c. setHealth(0)
  d. kill()
- die(source) 제거.
- discard() 사용하지 않음.
- ShulkerBullet은 LivingEntity가 아니므로 별도 인식하여 bullet.kill().

4. 망각의 오라 J
- 기존 invisibility/silent/Mob target 해제/VanillaGameEvent 차단 유지.
- 망각의 오라 사용자 반경 256블록 안의 ShulkerBullet을 틱 시작 즉시 kill하여 셜커 탄환 추적 자체를 차단.
- 서버 player.noPhysics=true + 클라이언트 예측 noPhysics=true로 블록 통과.
- 클라이언트에서 aura 중 블록 모델 RenderShape를 INVISIBLE로 만들고 canOcclude=false를 강제한 뒤 청크를 재빌드하여, 벽 뒤 지오메트리까지 컬링되지 않게 하는 투시 구현.
- aura 종료/왕관 해제 시 원래 noPhysics 상태 복원 및 렌더 청크 재빌드.

5. 도전과제
- ID: glitchedcrown:forbidden_domain
- frame: challenge
- icon: glitchedcrown:glitched_crown
- show_toast: true
- root background: End advancement background
- 기준: Crown이 인벤토리에 들어옴
- 비소유자 제목: CROWNLOCK! 10글자 + obfuscated
- Crown 소유자 제목: [금단의 영역]
- 기본 announce_to_chat은 끄고 Forge AdvancementEarnEvent에서 수신자별로 동일한 challenge 공개 메시지를 직접 전송하여, 소유/비소유자의 제목이 서로 다르게 보이도록 함.

6. 절멸 K
- 반경 75블록 실제 구형 범위.
- 모든 Player 제외.
- 보존: ArmorStand, HangingEntity, AbstractVillager, Iron/Snow Golem, Allay, ItemEntity, XP Orb, Boat, Minecart, 길들인 TamableAnimal, Interaction/Display/Marker/Leash Knot 계열.
- 나머지 비플레이어 엔티티 처리.
- LivingEntity: 삭제광선과 동일한 hurt(maxHealth) -> setHealth(0) -> kill() 전체 실행 후, 그래도 살아 있으면 discard().
- 비Living 처리 대상: kill() 후 남아 있으면 discard().
- 발동 즉시 처치 판정, 동시에 20틱 동안 금빛 구형 Dust 파동이 중심에서 75블록까지 확장.

7. 유지 사항
- CrownIntegrity 간섭자 처벌의 기존 discard fallback은 별도 능력이므로 유지.
- 삭제광선은 discard를 쓰지 않음.
- 중복 드롭 방지 로직은 추가하지 않음.
- 제작법과 FTB Quests는 복원하지 않음.

The Crowns 1.5.3
Minecraft 1.20.1 Forge / 네트워크 프로토콜 12

수정 사항

1. Curios head/hat 태그에 시간의 왕관, 서리의 왕관, 신성한 왕관,
   저주받은 왕관을 추가했습니다.

2. 시간의 왕관과 저주받은 왕관의 사망 유지 처리를 보강했습니다.
   - Forge LivingDeathEvent가 게시되기 전에 보존 대상 원본 스택을 격리합니다.
   - 바닐라 인벤토리/갑옷 및 Curios의 원래 슬롯 정보를 보존합니다.
   - 사망 취소 또는 리스폰 후 일회성 티켓을 먼저 소비하고 정확히 한 번 복원합니다.
   - 외부 모드가 같은 스택을 이미 보존한 경우 고유 마커로 중복 복원을 막습니다.
   - 일반 플레이 중 사라진 왕관을 재생성하는 로직은 사용하지 않습니다.
   - Curios drop rule에도 두 왕관의 ALWAYS_KEEP를 보조 방어로 적용합니다.

3. Tier I~III Crown이 저주받은 왕관으로 변환될 때
   Enchantment.isCurse()가 true인 모든 인챈트를 제거합니다.
   비저주 인챈트와 나머지 NBT는 유지합니다.

저주받은 왕관의 해제 예외(크리에이티브, Glitched, Unleashed, U²)는 유지됩니다.

추가 설명/밸런스 수정

4. 시간의 왕관과 신성한 왕관의 지정 상세 설명 문장을 아이템 툴팁과
   로어북에서 제거했습니다. 실제 능력 동작은 변경하지 않았습니다.

5. 서리의 왕관 설명을 동결/가루눈, 추운 곳의 생명체, 서리 가시,
   영원설의 네 문장으로 정리했습니다.
   - 기존 북극곰/스트레이 비적대를 유지합니다.
   - 기본 온도 0.15 이하의 차가운 바이옴에서는 드라운드도 착용자를
     적대하지 않습니다.

6. 저주받은 왕관의 귀속 설명을 간결하게 바꾸고, 크리에이티브 또는
   Glitched/Unleashed/U² 착용 여부에 따른 해제 안내를 조건부 표시합니다.

7. 저주받은 왕관의 해방 지속시간을 30초에서 60초로 상향했습니다.

8. 조건부 저주 해제 안내의 클라이언트 상태 조회를 전용 헬퍼로 격리해,
   전용 서버가 LocalPlayer 클래스 로드 오류 없이 시작되도록 수정했습니다.

9. Glitched/Unleashed/U²의 지속형 야간 투시와 수중 호흡을 4초마다
   30초씩 갱신해 야간 투시 종료 경고의 화면 깜빡임을 방지했습니다.

10. 해방 설명을 `자신의 저주에서 해방`으로 간결화하고 시전 직전 최대
    체력만큼 회복한다는 상세 문구를 제거했습니다. 실제 회복 동작은 유지합니다.

11. 저주 변환 원본을 명시적인 Tier I~III Crown 11종 allowlist로 제한해
    미래 Standard Crown이 의도치 않게 변환되지 않게 했습니다.

12. 시간·서리·신성·저주받은 왕관의 실제 동작 수치 38개를 월드별 SERVER
    config로 추가하고 툴팁·로어북 숫자도 설정값을 반영하게 했습니다.

13. 핵심 보호 Mixin 적용을 기록하는 config plugin, 접속 후 one-shot 감사,
    `/crown diagnostics` 관리자 명령을 추가했습니다.

14. README와 모드팩 개발자 문서를 1.5.3 기준으로 갱신하고 사용 허가,
    수익화 경계, 호환 목록, 차기 산출물 이름 규칙을 명시했습니다.

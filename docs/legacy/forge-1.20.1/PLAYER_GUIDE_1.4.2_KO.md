# The Crowns 1.4.2 — 일반 플레이어용 설명서

대상 버전: **Minecraft 1.20.1 / Forge 47.4.x / Java 17**  
모드 표시 이름: **The Crowns**  
내부 mod id: **`glitchedcrown`**  
필수 의존성: **Curios 5.14.1+**

> 이 문서는 1.4.2 실제 구현을 기준으로 작성했다. 1.4.1에서 남아 있던 Crown Builder/JEI/발전과제/자동화 차단/수리/외형 문제를 반영한 버전이다.

---

## 1. 모드 개요

The Crowns는 여러 종류의 왕관을 제작하고 장착해 전투, 생존, 이동, 소환, 회피, 부활, 절멸 계열 능력을 얻는 장비 모드다.

왕관은 크게 네 개의 제작 단계로 나뉜다.

| Builder 티어 | 제작 가능한 왕관 |
|---|---|
| **I** | 불타는 왕관, 강철화 왕관 |
| **II** | 핏빛 왕관, 암흑의 왕관, 전사의 왕관 |
| **III** | 빛의 왕관, 차원의 왕관, 천사의 왕관 |
| **IV** | 글리치 왕관, 해방된 왕관 |
| 없음 | 해방된 해방된 왕관(U²) — 관리자 전용 |

1.4.2부터 대부분의 Crown은 일반 작업대가 아니라 **Crown Builder**에서 제작한다.

---

## 2. 장착과 공통 규칙

### 장착 슬롯

모든 Crown은 다음 위치에서 감지된다.

- 바닐라 **머리(Helmet)** 슬롯
- Curios의 **Head** 슬롯
- Curios의 **Hat** 슬롯

모드팩이 Head/Hat 슬롯을 여러 개 제공한다면 서로 다른 Crown 능력이 동시에 활성화될 수 있다.

1.4.2에서는 **같은 종류의 Crown을 바닐라 머리 슬롯과 Curios 슬롯에 중복 장착할 수 없다.** 서로 다른 종류의 Crown은 여러 Head/Hat 슬롯을 이용해 동시에 장착할 수 있다.

### 툴팁

Crown에 커서를 올리면 기본적으로 다음만 표시된다.

- `슬롯 : 머리`
- `Shift를 눌러 자세한 설명을 확인하세요.`

**Shift를 누르면** 스탯, 패시브, 액티브, 현재 쿨다운, 현재 키 설정 등이 표시된다.

### 키 설정

기본 키는 다음과 같다.

| 능력 | 기본 키 |
|---|---:|
| 글리치/해방 계열 삭제 광선 | **G** |
| 해방 계열 종말의 힘 | **H** |
| 해방 계열 망각의 장막 | **J** |
| 해방 계열 절멸 | **K** |
| 강철화 왕관 — 강철의 수호자 | **K** |
| 전사의 왕관 — 결투 | **K** |
| 천사의 왕관 — 창공날기 | **K** |

각 능력은 **별도의 KeyMapping**이므로 조작 설정에서 따로 변경할 수 있다. 여러 K 능력을 동시에 사용할 수 있는 장비 구성이면 충돌을 피하기 위해 키를 재지정하는 것을 권장한다.

### 내구도와 인챈트

- Tier I~III 일반 Crown: **내구도 4096**
- 글리치 왕관 / 해방된 왕관 / U²: 실질적으로 **Unbreakable**
- 일반 투구에 적용 가능한 바닐라/모드 인챈트는 Crown에도 적용 가능하도록 되어 있다.
- Mending, Unbreaking 계열도 투구 호환 인챈트라면 사용할 수 있다.
- Tier I~III 일반 Crown은 **Nether Star 1개로 최대 내구도의 25%를 모루에서 수리**할 수 있다.
- 해당 전용 수리의 모루 레벨 비용은 **10**이다.

# 3. Crown Builder

## 기본 사용법

Crown Builder를 설치하고 우클릭하면 다음 구조의 GUI가 열린다.

- 왼쪽: **실제 3×3 입력 인벤토리**
- 오른쪽: **가상 결과 슬롯**
- 아래: 플레이어 인벤토리

결과 슬롯은 저장 공간이 아니다. 제작 조건이 맞을 때만 결과가 보이고, 플레이어가 결과를 가져가는 순간 입력이 소비된다.

### 내부 아이템 보존

Builder의 9칸 입력은 다음 상황에서도 보존되도록 구현되어 있다.

- GUI 닫기
- 청크 언로드
- 서버 재시작
- Builder 블록 파괴 후 아이템화
- 다시 설치
- 상위 Tier Builder로 업그레이드

Builder 업그레이드 결과는 중앙에 사용한 이전 Builder의 `BlockEntityTag`를 이어받는다.

### Builder 안에 Builder 넣기

Crown Builder 아이템은 Crown Builder 입력칸에 넣을 수 없도록 차단되어 있다.

### Crafting remainder

물 양동이/용암 양동이처럼 제작 후 빈 용기가 남는 아이템은 가급적 **원래 입력칸에 remainder가 남는다.**

현재 슬롯 상태 때문에 remainder를 안전하게 되돌릴 수 없다면 결과를 가져가지 못하게 막는다.

# 4. Builder 제작법

표는 위에서 아래로 3줄을 의미한다.

## Crown Builder I

```text
철 블록       모루             철 블록
자수정 블록   다이아몬드 블록  자수정 블록
철 블록       작업대           철 블록
```

## Crown Builder II

```text
금 블록           마법부여대             금 블록
네더라이트 주괴   Crown Builder I        네더라이트 주괴
금 블록           위더 스켈레톤 해골     금 블록
```

업그레이드이므로 Builder I 내부 9칸 내용이 Builder II로 이어진다.

## Crown Builder III

```text
다이아몬드 블록   드래곤 머리            다이아몬드 블록
엔드 막대         Crown Builder II       엔드 막대
다이아몬드 블록   셜커 껍데기            다이아몬드 블록
```

## Crown Builder IV

```text
네더라이트 블록         압축된 에메랄드 블록   네더라이트 블록
압축된 에메랄드 블록   Crown Builder III     압축된 에메랄드 블록
네더라이트 블록         압축된 에메랄드 블록   네더라이트 블록
```

1.4.2에서는 원래 설계한 **네더라이트 블록 모서리 / 압축된 에메랄드 블록 변 / Builder III 중앙** 배치로 통일되었다.

## 압축된 에메랄드 블록

```text
에메랄드 블록 ×9 → 압축된 에메랄드 블록 ×1
```

반대로 압축된 에메랄드 블록 1개를 단독 제작하면 에메랄드 블록 9개로 되돌릴 수 있다.

# 6. Tier I Crown

## 불타는 왕관 — `glitchedcrown:burning_crown`

### 제작법 — Builder I 이상

```text
화염구      블레이즈 막대   화염구
금 블록     네더라이트 주괴 금 블록
화염구      용암 양동이     화염구
```

용암 양동이는 제작 후 빈 양동이가 remainder로 남는다.

### 스탯

- 최대 체력 **+10**
- 방어력 **+10**
- 방어 강도 **+5**

### 능력

- 불 및 용암 피해 면역
- 독, 시듦, 둔화, 멀미 효과 제거/면역
- 피격 시 공격자에게 불꽃 반격
- 기본 반격 피해: **4**
- 기본 연소 시간: **4초**
- 반격 피해 = `4 + 현재 방어력 × 0.5`
- 연소 시간 = `4초 + 현재 방어 강도 × 0.5초`
- 동일 대상 반격 쿨다운: **1초**

투사체 공격이라도 실제 공격자를 추적할 수 있으면 그 공격자에게 반격한다.

---

## 강철화 왕관 — `glitchedcrown:ironforged_crown`

### 제작법 — Builder I 이상

```text
철 블록       에메랄드 블록      철 블록
모루          Ironforged Core    모루
철 블록       다이아몬드 블록    철 블록
```

### 스탯

- 방어력 **+30**
- 방어 강도 **+30**
- 이동속도 **-10%**

### 액티브 — 강철의 수호자

- 기본 키: **K**
- 쿨다운: **120초**
- 아군 Iron Golem 1기를 소환
- 소환 시 플레이어의 현재:
  - 최대 체력
  - 방어력
  - 방어 강도
  를 골렘 기본 능력치에 추가한다.
- 한 플레이어에게 등록되는 수호자는 1기다. 새로 소환하면 기존 등록 골렘은 제거된다.
- 플레이어가 공격한 대상, 플레이어를 공격한 대상을 공격하도록 보조한다.
- 일반 Iron Golem과 달리 Creeper도 공격 대상으로 잡을 수 있다.
- 같은 FTB Teams/바닐라 팀의 플레이어는 공격하지 않도록 보호된다.

# 7. Tier II Crown

## 핏빛 왕관 — `glitchedcrown:bloody_crown`

### 제작법 — Builder II 이상

```text
Big Rotten Flesh Block   블레이즈 막대       Big Rotten Flesh Block
레드스톤 블록            네더라이트 주괴     레드스톤 블록
Big Rotten Flesh Block   엔드 수정           Big Rotten Flesh Block
```

### 스탯

- 최대 체력 **+50**
- 최대 체력 **+15%**
- 최종 피해 기준 **15% 생명력 흡수**
- 3초 동안 피해를 받지 않으면 초당 1 HP 재생

### 피의 축복

- 직접 근접 공격으로 유효한 적을 처치하면 발동
- 최대 체력의 **20% 회복**
- 영구 최대 체력 **+1**
- 최대 **50스택**
- 50스택 이후에도 회복 효과 자체는 발동 가능
- 발동 쿨다운: **30초**
- 피해를 받을 때마다 남은 쿨다운 **1초 감소**

유효 처치 대상은 적대 몹 또는 실제로 플레이어에게 분노한 중립 몹이다. 활/투사체/폭발/마법/소환수 처치는 피의 축복 성장 조건으로 인정되지 않는다.

획득한 영구 체력 스택은 왕관을 벗어도 유지된다.

## 암흑의 왕관 — `glitchedcrown:darkened_crown`

### 제작법 — Builder II 이상

```text
금박 흑암석          끌로 다듬은 윤나는 흑암석   금박 흑암석
메아리 조각          스컬크 촉매                  메아리 조각
우는 흑요석          흑요석                       우는 흑요석
```

### 스탯

- 방어력 **+20**
- 이동속도 **+10%**

### 능력

- 가하는 최종 피해 **×2**
- 받는 최종 피해 **×1.5**
- Darkness 면역
- Blindness 면역
- **8초마다 다음 공격 1회 완전 회피**
- Warden은 기본적으로 착용자를 공격 대상으로 잡지 않는다.

착용자가 특정 Warden을 먼저 공격하면 그 Warden에 대해서는 중립 보호가 해제된다. 해당 Warden의 분노가 자연스럽게 끝나면 다시 보호된다.

## 전사의 왕관 — `glitchedcrown:warrior_crown`

### 제작법 — Builder II 이상

```text
힘 II 포션          블레이즈 막대       네더라이트 검
철 블록             고대 잔해           철 블록
네더라이트 도끼     모루                삼지창
```

좌상단 포션은 반드시 **힘 II(Strong Strength)** 포션이어야 한다.

### 스탯

- 최대 체력 **+20**
- 공격력 **+20**
- 방어력 **-20%**
- 방어 강도 **-20%**
- 활/석궁 사용 불가

### 액티브 — 결투

- 기본 키: **K**
- 지속시간: **15초**
- 쿨다운: **120초**
- 결투 중 공격속도 **+25%**
- 결투 중 착용자에게 들어오는 피해는 **직접 근접 피해만 허용**된다.
- 투사체, 폭발, 불, 마법/주문 계열, 환경 피해 등은 막힌다.
- 시전 시 최대 약 32블록 시선상의 유효 대상을 찾는다.
- 대상에게 15초간:
  - 둔화 II
  - 나약함 II
  - 실명 II
- 표식 유지 중 대상을 처치하면 결투 쿨다운 **30초 감소**

플레이어, 적대 몹, 중립 몹을 표식 대상으로 삼을 수 있다. 일반적인 비공격적 생명체는 대상에서 제외된다.

# 8. Tier III Crown

## 빛의 왕관 — `glitchedcrown:crown_of_light`

1.4.2부터 아이템 아이콘은 천사의 왕관과 구분하기 위해 **빛나는 푸른색/청록색 계열**로 변경되었다.

### 제작법 — Builder III 이상

```text
발광석        자수정 싹        발광석
다이아몬드 블록   신호기       에메랄드 블록
발광석        메아리 조각      발광석
```

자수정 싹은 Small / Medium / Large Amethyst Bud 중 하나를 사용할 수 있다.

### 스탯

- 최대 체력 **+20**
- 방어력 **+15**
- 방어 강도 **+7**

### 체력 50% 이상일 때

- 가하는 최종 피해 **×1.5**
- 이동속도 **+20%**
- 받는 최종 피해 **×0.65** — 즉 35% 감소

체력이 최대 체력의 절반 아래로 내려가면 조건부 강화는 즉시 사라진다.

## 차원의 왕관 — `glitchedcrown:dimensional_crown`

### 제작법 — Builder III 이상

```text
엔더의 눈      터진 후렴과       엔더의 눈
마법부여대      드래곤 머리       마법이 부여된 책
엔더의 눈      후렴화             엔더의 눈
```

오른쪽 가운데 책은 단순 `Enchanted Book` 아이템이면 충분한 것이 아니라 **실제로 인챈트가 하나 이상 들어 있어야 한다.**

### 스탯

- 이동속도 **+30%**
- 공격력 **+10**
- 공격속도 **+20%**

### 능력

- 적/엔티티에서 유래한 피해를 **35% 확률로 완전 회피**
- 10초마다 다음 공격이 **최종 피해 ×3**
- 회피 성공 시 아직 충전 중인 강화 공격 쿨다운 **1초 감소**
- 공허 피해 면역
- Y < -200이면 같은 X/Z 좌표의 높은 위치로 구조
  - 일반 차원에서는 Y=300
  - 차원의 최대 건축 높이가 낮으면 그보다 조금 아래로 조정
- 구조 후 실제 땅에 착지할 때까지 낙하 피해 보호
- 몬스터가 처음 착용자를 탐지할 수 있는 실질 거리 **50% 감소**

## 천사의 왕관 — `glitchedcrown:angelic_crown`

### 제작법 — Builder III 이상


# 13. 자주 헷갈리는 점

### Q. 글리치 왕관을 만들었는데 능력이 안 켜진다.
기본 설정에서는 발전과제 점수 4점이 필요하다. 착용 시 조건이 부족하면 경고가 표시된다.

### Q. K를 누르면 왜 여러 능력이 같이 발동할 수 있나?
강철화/전사/천사/Unleashed 절멸이 모두 기본 K지만 서로 별도 키 설정이다. 조작 설정에서 각자 다른 키로 바꾸면 된다.

### Q. 빛의 왕관과 천사의 왕관 외형이 헷갈린다.
1.4.2에서 **빛의 왕관 아이템 아이콘과 실제 장착 텍스처 모두** 밝게 빛나는 청록/푸른색 계열이다. 천사의 왕관은 별도의 금빛/백색 계열 장착 텍스처를 사용한다.

### Q. JEI에서 Crown Builder 레시피를 볼 수 있나?
JEI 15.20+가 설치되어 있으면 **Crown Builder 전용 카테고리**가 등록된다. 각 레시피에는 필요한 Builder Tier가 I~IV로 표시되고, `+` 버튼으로 현재 Builder에 재료를 전송할 수 있다. 현재 Builder의 Tier가 부족하면 전송이 거부된다.

### Q. 글리치 왕관 제작 때 드래곤 알이 사라지나?
1.4.2의 Crown Builder 레시피에서는 **항상 반환**된다.

# 14. 1.4.2에서 보강된 시스템과 주의사항

1.4.1에서 남아 있던 다음 항목은 1.4.2에서 보강되었다.

- Crown Builder 전용 JEI 카테고리 및 `+` recipe transfer
- The Crowns → Builder I → Tier별 Crown 완료 → Builder II/III/IV → Glitched → 숨김 Unleashed 발전과제 흐름
- Builder 외부 자동화 차단: BlockEntity가 외부 `Container`/ItemHandler를 노출하지 않는 구조
- T3/T4 Builder 드롭 아이템 보호: 자연 despawn/일반 damage 방지, T4 공허 구조
- Builder/압축 에메랄드 블록 Creative Tab 등록
- Glitched/Unleashed Builder recipe와 서버 recipe config 재연결
- Tier IV Builder 레시피 원안 복원
- 일반 Crown Nether Star 25% 모루 수리 / 비용 10
- 동일 종류 Crown 중복 장착 차단
- Tier I~III 장착 텍스처 분리 및 빛의 왕관 청록/푸른색 장착 외형

### 남아 있는 실전 확인 범위

- 외부 모드가 vanilla/Forge 인벤토리 API나 Explosion API를 거치지 않고 블록/엔티티를 직접 삭제하는 경우까지 Builder를 보호하지는 않는다.
- JEI가 없는 환경에서는 JEI 카테고리와 `+` 전송이 나타나지 않지만 Crown Builder 자체 제작에는 영향이 없다.
- 대형 모드팩에서의 모든 타 모드 상호작용은 실제 서버에서 별도 회귀 테스트가 필요하다.

## 버전 요약

**The Crowns 1.4.2**의 핵심은 다음 세 가지다.

1. 11종 Crown 능력 체계
2. Tier I~IV Crown Builder를 통한 진행형 제작
3. Crown Builder/JEI/발전과제 진행 체계와 **빛나는 푸른색 빛의 왕관** 외형 보강

최종급 Glitched/Unleashed는 일반 장비보다 훨씬 강력하며, 모드팩 서버에서는 서버 설정에 따라 수치와 기능이 크게 달라질 수 있다.

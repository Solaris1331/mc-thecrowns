Glitched Crown 1.0.6 - BuildFix2
================================

2026-08-09 빌드 로그에서 확인된 컴파일 오류 2개 수정:

1) CrownIntegrity.java
- record CrownLocation(boolean helmet, ...)가 자동 생성하는 public helmet() 접근자와
  private static CrownLocation helmet() 팩토리 메서드가 충돌함.
- 정적 팩토리 메서드를 forHelmet()로 변경하고 호출부도 전부 갱신.

2) CrownLogic.java
- ResourceLocation 사용부의 import 누락 수정:
  import net.minecraft.resources.ResourceLocation;

추가 정리:
- Curios DynamicStackHandler가 compileClasspath에 들어온 상태이므로
  문자열 targets= 대신 @Mixin(value = DynamicStackHandler.class, remap=false) 사용.
  이전 로그의 "public and should be specified in value" 경고를 제거하기 위한 정리이며
  동작 의미는 동일함.

삭제광선/절대 아이템 무결성의 기능 로직은 변경하지 않음.

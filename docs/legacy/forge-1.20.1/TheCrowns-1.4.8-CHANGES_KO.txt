The Crowns 1.4.8 - Forge 1.20.1 변경 명세
============================================================

1. 조합법 뷰어 자동 감지
- 클라이언트 초기화 시 Forge ModList를 사용해 다음 3개 모드를 각각 감지한다.
  * JEI: mod id `jei`
  * EMI: mod id `emi`
  * REI: mod id `roughlyenoughitems`
- 감지 결과는 로그에 한 줄로 기록한다.
- 셋 중 여러 개가 동시에 설치되어 있어도 각 네이티브 플러그인이 독립적으로 등록된다.
- 셋 모두 없으면 The Crowns 본체/Crown Builder에는 영향이 없다.

2. JEI 지원 보강
- 기존 Crown Builder 전용 JEI category 유지.
- Builder I~IV catalyst 유지.
- 필요 Builder Tier 표시 유지.
- JEI + recipe transfer 및 낮은 Builder Tier 거부 유지.
- JEI runtime이 월드 recipe sync보다 먼저 준비되는 경우에도 recipes가 0개로 고정되지 않도록 개선.
- `RecipesUpdatedEvent` 발생 후 실제 client RecipeManager를 사용해 Crown Builder recipes를 등록한다.

3. EMI 네이티브 지원 추가
- `@EmiEntrypoint` 네이티브 EMI plugin 추가.
- Crown Builder 전용 EMI recipe category 추가.
- Builder I~IV workstation 등록.
- glitchedcrown:crown_builder recipe type을 직접 읽어 표시.
- exact Potion 요구 슬롯은 실제 지정 Potion ItemStack으로 표시.
- Crown Builder menu에 표준 EMI recipe transfer handler 등록.
- 현재 열려 있는 Builder의 Tier가 recipe 요구 Tier보다 낮으면 transfer 지원 대상으로 취급하지 않는다.
- 필요 Builder Tier 문구는 EMI widget API에서 지원되는 경우 표시한다.

4. REI 네이티브 지원 추가
- Forge `@REIPluginClient` + `REIClientPlugin` 네이티브 plugin 추가.
- Crown Builder 전용 REI category/display 추가.
- Builder I~IV workstation 등록.
- glitchedcrown:crown_builder recipe type에 recipe filler 등록.
- exact Potion 요구 슬롯은 실제 지정 Potion ItemStack으로 표시.
- Crown Builder 입력 9칸 + 플레이어 인벤토리를 대상으로 SimpleTransferHandler 등록.
- 필요 Builder Tier를 recipe 화면에 표시.

5. 선택적 의존성
- JEI / EMI / REI 모두 client-side optional dependency다.
- 지원 범위:
  * JEI 15.20+
  * EMI 1.1.x
  * REI 12.x (Minecraft 1.20/1.20.1 계열)
- 각 API는 본체 JAR에 번들하지 않는다.
- 오프라인 빌드를 위한 compile-only stub source set만 별도로 사용하며 최종 JAR에는 포함하지 않는다.

6. 호환성 / 기타
- Minecraft 1.20.1 / Forge 47.4.x / Java 17.
- Curios 5.14.1+ 필수.
- 네트워크 패킷 형식 변경 없음: protocol 9 유지.
- Crown 능력/밸런스/Crown Builder UI/Creative Tab 동작은 1.4.7에서 변경하지 않음.

# The Crowns 1.5.3

Minecraft 1.20.1 / Forge 47.4.x용 Crown 장비·진행 모드입니다. 열다섯 Crown, Crown Builder I~IV, 한·영 로어북, 서버 권한형 최종 능력을 제공합니다.

## 요구 환경

- Minecraft 1.20.1
- Forge 47.4.x
- Java 17
- Curios 5.14.1+

JEI 15.20+, EMI 1.1.x, REI 12.x는 선택적 클라이언트 연동입니다. 모든 Crown은 바닐라 머리 슬롯과 Curios `head`/`hat` 슬롯을 지원합니다.

## 1.5.3 핵심

- 시간·서리·신성·저주받은 왕관과 Builder 진행 추가
- 신규 Crown 4종의 밸런스 수치 38개를 월드별 SERVER config로 제공
- 설정값을 아이템 툴팁과 `제왕의 길` 로어북에 동적으로 표시
- 저주 변환 대상을 명시적인 Tier I~III 목록으로 제한
- 시간·저주 Crown의 one-shot 사망 유지
- `/crown diagnostics` Mixin 적용 상태 진단
- JEI·EMI·REI용 Crown Builder 레시피 카테고리

모드팩 연동 세부사항은 [MODPACK_DEVELOPER_GUIDE_1.5.3_KO.md](MODPACK_DEVELOPER_GUIDE_1.5.3_KO.md)를 참고하세요.

# The Crowns 1.0.4

## 배포 파일

- `thecrowns-forge-1.20.1-1.0.4.jar` — Forge 1.20.1, Java 17
- `thecrowns-neoforge-1.21.1-1.0.4.jar` — NeoForge 1.21.1, Java 21

두 파일은 이 릴리스의 동일한 소스 스냅샷에서 생성한 보관본입니다. NeoForge 1.21은 아직 완성·검증된 배포 대상이 아니므로 JAR를 제공하지 않습니다.

## 1.0.4 변경사항

- 그림자 왕관과 심해의 왕관, 각 제조법·로어북·전용 아이콘/장비 외형을 추가했습니다.
- 두 왕관의 Glitched Crown 융합 계승 능력을 추가했습니다.
- Curios 착용 지원을 보완했습니다.
- 동일한 일반 아이템이 인벤토리에서 분리되는 문제를 수정했습니다.
- Enhanced AI의 강제 순간이동을 그림자 왕관의 강제 이동 저항으로 인식하도록 보완했습니다.
- 불·환경 피해에서 발생할 수 있는 광범위한 이동 차단을 제거했습니다.
- Iron Guardian 최종 피해 제한을 호환 가능한 이벤트 방식으로 옮겼습니다.

## 이 라인의 이력

- **1.0.0-beta.1**: `thecrowns` 네임스페이스 기반 Forge 1.20.1 라인을 시작했습니다.
- **1.0.2-beta.1**: 1.20.1 밸런스/설명문 개정을 확정하고 NeoForge 1.21·1.21.1 이식 기반을 마련했습니다.
- **1.0.3**: Curios 전용 왕관 슬롯, 명령어/쿨다운 제어, 천사의 왕관 비행 및 조합 뷰어 보완을 추가했습니다.
- **1.0.4**: 그림자·심해의 왕관과 호환성/인벤토리 수정이 포함된 현재 배포본입니다.

`thecrowns` 라인에는 1.0.1 독립 배포본이 기록되어 있지 않습니다. 과거 1.0.0~1.0.3의 별도 JAR도 보관되어 있지 않아, 이 릴리스에는 실제 검증된 1.0.4 JAR만 첨부합니다. 전체 상세 변경 내역은 루트의 `CHANGELOG.md`와 `releases/1.0.4/MOD_DESCRIPTION_KO.md`에 있습니다.
